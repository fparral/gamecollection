<h1>🇬🇧 SECCIÓN EN INGLÉS</h1>

<h2>🧩 1. Uso de <em>who</em> y <em>whom</em></h2>

<p><strong>Rule:</strong><br>

- <strong>who</strong> = subject<br>

- <strong>whom</strong> = object</p>

<p><strong>Quick trick:</strong><br>

- If you can replace it with <strong>he/she</strong>, use <em>who</em>.<br>

- If you can replace it with <strong>him/her</strong>, use <em>whom</em>.</p>

<p><strong>Examples:</strong><br>

- <em>Who called you?</em> → <span class="trad">Él te llamó.</span><br>

- <em>Whom did you call?</em> → <span class="trad">Tú lo llamaste a él.</span></p>
